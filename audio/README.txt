Roscoe's Wonder Lab — Audio Files

Drop MP3 files into the folders below using the exact filenames shown.
The app remains usable when files are missing; missing audio fails silently.

MIXING IS HANDLED IN CODE
- Voice responses: loudest
- One-shot action sounds: medium
- UI clicks/toggles: quieter
- Motion collisions/bounces: quiet and rate-limited
- Ambient loops: quietest and automatically reduced when several are active
- Ambient loops are temporarily ducked while a voice response speaks

Recommended preparation
- MP3 format
- Similar perceived loudness across one-shot sounds
- No clipping
- Minimal silence at the beginning of one-shots
- Seamless loop points for looping switch sounds
- Keep sounds calm and toddler-friendly

See the README files in each subfolder for exact behavior.
